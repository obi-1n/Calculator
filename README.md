# Calculator

A lightweight browser-based calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Decimal input support
- Clear and delete actions
- Keyboard support for digits, operators, Enter, Backspace, and Escape
- Responsive layout that works in the browser

## Project structure

- `index.html` — app markup and calculator layout
- `styles.css` — calculator styling
- `script.js` — calculator logic and event handling

## Run locally

You can open `index.html` directly in a browser, or serve the folder locally:

```bash
cd /Users/anthonynnegha/Desktop/Calculator
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Usage

- Click the calculator buttons to perform operations.
- Use the keyboard for quick input.
- Press `=` to evaluate an expression or `AC` to reset the calculator.

## Notes

This project is a small front-end app and does not require any build tools or package installation.
